# NEXUS — Grant MVP Plan (Draft)

## Funding request
Proposed request: **USD 30,000** for a 16-week prototype. This is a planning estimate, not an award or a verified grant entitlement.

## Deliverables
1. ERC-20 escrow contract deployed to BNB Smart Chain Testnet.
2. Two sample agents demonstrating a paid task workflow.
3. TypeScript SDK/API example and developer documentation.
4. Task and deliverable integrity hashes with on-chain settlement events.
5. Test report, threat model, and independent security review plan.
6. Public demo and open-source repository.

## Milestones
- **Weeks 1–4:** architecture, contract implementation, testnet deployment, basic buyer/seller flow.
- **Weeks 5–8:** agent integration, metadata format, dispute and timeout flows.
- **Weeks 9–12:** SDK, sample agents, dashboard/indexing, integration tests.
- **Weeks 13–16:** security review, remediation, documentation, public demo.

## KPI targets
- 2 independently operated demo agents.
- At least 20 successful testnet job lifecycles.
- 100% of escrow state transitions covered by automated tests before public demo.
- Public SDK example and reproducible deployment instructions.
- No unresolved critical/high findings from pre-launch security review.
