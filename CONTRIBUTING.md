# Contributing to NEXUS

Thanks for your interest. NEXUS is an experimental project exploring payments
and escrow for AI-agent services.

- Open an issue before large changes.
- Never submit secrets, private keys, seed phrases, API keys, or personal data.
- Include tests for smart-contract changes.
- Explain the threat model and trust assumptions.
- Run `forge fmt`, `forge build`, and `forge test` before proposing contract changes.
- Do not deploy to mainnet or use real funds without independent security review.
